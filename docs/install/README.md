# Руководство по настройке среды разработки (Android)

Этот документ описывает процесс настройки локального окружения для сборки, запуска и тестирования
Android-версии игры **Nsiay Tetris**.

## Системные требования

- **ОС**: Windows 10/11, macOS или Linux.
- **ОЗУ**: Минимум 8 ГБ (рекомендуется 16 ГБ для комфортной работы эмулятора).
- **Диск**: Минимум 10 ГБ свободного места (Android Studio + SDK + Эмулятор).

---

## Шаг 1. Установка Android Studio

1. Перейдите на официальный
   сайт: [developer.android.com/studio](https://developer.android.com/studio).
2. Скачайте установщик для вашей ОС и запустите его.
3. В процессе установки выберите тип **Standard** (Стандартная). Это автоматически скачает базовый
   Android SDK.
4. Примите лицензионные соглашения (кнопка **Accept** для всех пунктов).
5. Дождитесь окончания загрузки всех компонентов.

> ⚠️ **Важно (Windows):** Чтобы избежать ошибок `Failed to read or create install properties file` и
> сильного замедления сборки, добавьте папки проекта и SDK в исключения Microsoft Defender (или
> вашего
> антивируса).
> Пути для исключения:
> - `C:\Users\<Username>\AppData\Local\Android\Sdk`
> - `C:\Users\<Username>\.gradle`
> - Путь к папке с проектом.

---

## Шаг 2. Настройка эмулятора (Android Virtual Device)

Для запуска инструментальных тестов и игры нам понадобится виртуальное устройство.

1. В Android Studio откройте **Tools** -> **Device Manager**.
2. Нажмите **Create Device** (или значок `+`).
3. Выберите категорию **Phone** и модель **Pixel 6**. Нажмите **Next**.
4. Выберите системный образ **API 37.0 (Android 17)** или **API 34.0** (в зависимости от вашей
   версии SDK). Нажмите значок скачивания (Download) рядом с образом, если он еще не загружен.
5. Дождитесь загрузки системного образа (около 2 ГБ).
6. Нажмите **Finish**. Запустите эмулятор, нажав на зеленую стрелку **Play (▶)** в Device Manager.

---

## Шаг 3. Импорт и сборка проекта

1. Запустите Android Studio.
2. На экране приветствия выберите **Open** (или **File** -> **Open**).
3. Укажите путь к папке проекта `NsiayTetris`.
4. Если появится окно "Trust Project", нажмите **Trust**.
5. Дождитесь окончания синхронизации Gradle (внизу экрана будет бежать полоса загрузки).

### Запуск игры

1. Убедитесь, что эмулятор Pixel 6 запущен.
2. Нажмите зеленую кнопку **Run (▶)** на верхней панели (или `Shift + F10`).
3. Android Studio соберет APK, установит его на эмулятор и запустит игру.
4. При первом запуске появится системное окно "Viewing full screen" — нажмите **Got it**, чтобы
   перейти в полноэкранный режим.

## Шаг 4. Запуск тестов

Проект содержит два типа тестов: локальные (Unit) и инструментальные (Instrumented).

### Локальные тесты (без эмулятора)

Проверяют бизнес-логику (Board, GameState). Выполняются на JVM за пару секунд.
В терминале Android Studio выполните:

```bash
./gradlew test
```

### Инструментальные тесты (требуют эмулятора)

Проверяют работу с Android SDK (сохранение рекордов через SharedPreferences).
Убедитесь, что эмулятор запущен, и выполните:

```bash
./gradlew connectedAndroidTest
```

### Анализ покрытия кода тестами (JaCoCo)

Для генерации HTML-отчета о том, какой процент кода покрыт тестами, выполните:

```bash
./gradlew jacocoDebugCoverage
```

После завершения сборки откройте в браузере файл:
`app/build/reports/jacoco/jacocoDebugCoverage/html/index.html`, чтобы увидеть детальную статистику
по классам и методам.

## Шаг 5. Сборка APK файла

Если вам нужен готовый установочный файл для передачи на реальный телефон:

1. В меню Android Studio выберите `Build -> Generate App Bundles or APKs -> Generate APK (s)`.
2. После завершения сборки нажмите на ссылку **locate** в появившемся уведомлении.
3. Готовый файл `NsiayTetris-debug.apk` будет находиться в папке `app/build/outputs/apk/debug/`.

## Примечание: Если вы создаете проект с нуля

Если вы хотите не просто открыть готовый исходный код, а создать каркас проекта заново, вам нужно
правильно выбрать шаблон в Android Studio:

1. Нажмите **New Project**.
2. В списке шаблонов найдите и выберите **Empty Views Activity** (именно *Views*, а не просто *Empty
   Activity*).
   > ⚠️ **Почему это важно?** Шаблон `Empty Activity` в новых версиях Android Studio использует
   Jetpack Compose (декларативный UI). Наша же игра написана на классическом XML + `SurfaceView`,
   поэтому нам нужен шаблон `Empty Views Activity`.
3. Заполните поля:
    - **Name:** `NsiayTetris`
    - **Package name:** `nsi.example.tetris`
    - **Language:** `Kotlin`
    - **Minimum SDK:** `API 24 (Android 7.0)`
4. Нажмите **Finish**.
